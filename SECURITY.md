# Reporting security issues / 安全问题报告

Please do not open a public issue for a security problem in Yew Harness, and please keep the details private until it is fixed.

- Email <support@tenonai.cn> with "Yew Harness security" in the subject. We reply within one business day.
- Or use this repository's private "Report a vulnerability" on GitHub.
- Tenon AI's [security policy](https://tenonai.cn/security/#report) describes how reports are handled.

Include the affected version or commit, steps to reproduce and the impact you expect. Never include real passwords, keys, tokens or personal data, such as model API keys, MCP sign-ins or session contents.

Fixes go into the latest release.

Scope: the desktop service and web interface in this repository (the npm package `@tenonai/yew`), the system sandbox's configuration, the iPhone and Android apps, and the relay (`relay/`, and relay.tenonai.cn run by Tenon AI).

---

发现 Yew Harness 的安全问题，请不要开公开的 issue，也请在修好之前不要公开细节。

- 邮件：<support@tenonai.cn>，标题注明「Yew Harness 安全」，我们会在 1 个工作日内回复。
- 或者用本仓库 GitHub 的「Report a vulnerability」（私下报告）。
- 报告和答复的做法见榫卯 Tenon AI 的[安全政策](https://tenonai.cn/security/#report)。

请写明：受影响的版本或提交、复现步骤、你认为的影响。请不要在报告里放真实的密码、密钥、令牌或个人数据，以及模型的 API Key、MCP 登录信息和会话内容。

修复只进最新发布的版本。

范围：这个仓库里的电脑端服务和网页界面（npm 包 `@tenonai/yew`）、系统沙箱的配置、iPhone 应用、安卓应用和中继（`relay/`，以及榫卯 Tenon AI 运行的 relay.tenonai.cn）。
