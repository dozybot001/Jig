# 安全问题报告 / Reporting security issues

发现 Yew Harness 的安全问题，请不要开公开的 issue。

- 邮件：<support@tenonai.cn>，标题注明「Yew Harness 安全」。
- 或者用 GitHub 的「Report a vulnerability」（私下报告）。
- 报告和答复的做法见榫卯 Tenon AI 的[安全政策](https://tenonai.cn/security/#report)。

请写明：受影响的版本或提交、复现步骤、你认为的影响。请不要在报告里放真实的 API Key、登录链接或令牌，也不要放会话内容。

范围：这个仓库里的电脑端服务和网页界面（npm 包 `@tenonai/yew`）、系统沙箱的配置、iPhone 应用、安卓应用和中继（`relay/`，以及 Tenon AI 运行的 relay.tenonai.cn）。

Please do not open a public issue for a security problem in Yew Harness. Email <support@tenonai.cn> with "Yew Harness security" in the subject, or use GitHub's private "Report a vulnerability". Tenon AI's [security policy](https://tenonai.cn/security/#report) describes how reports are handled. Include the affected version or commit, steps to reproduce and the impact you expect. Never include real API keys, sign-in links or tokens, or session contents.

Scope: the desktop service and web interface in this repository (the npm package `@tenonai/yew`), the system sandbox's configuration, the iPhone and Android apps, and the relay (`relay/`, and relay.tenonai.cn run by Tenon AI).
